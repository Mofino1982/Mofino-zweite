Mo‘s Abo · Registrierung & Überweisung

Öffentlich → kostenlos → Abo

index.html ist die öffentliche Mo‘s Abo-Seite. Café und Autowäsche öffnen den kostenlosen Kontozugang. Ein Konto gilt für beide Bereiche. Firmen und Kunden haben eigene Seiten: cafe-kunden.html, cafe-firmen.html, autowaschen-kunden.html und autowaschen-firmen.html. Neue Konten bestätigen ihre E-Mail. Die Startseite erhält keine anonyme Besucherzählung.

Registrierungen werden in platformProfiles gespeichert; bestätigte Kundenaufrufe in platformViews. Der zentrale Admin zeigt bis zu 500 Datensätze pro Liste und kennzeichnet eine Begrenzung. Alte Konten erscheinen erst nach ihrem nächsten Aufruf in der neuen Kontenübersicht. Das Anlegen eines Kontos erzeugt weder Guthaben noch einen Zahlungsnachweis.

Live-Voraussetzungen

Die Café-Einlösung verwendet die enthaltenen Functions createMemberCode, previewDrink und redeemDrink (Region europe-west3). Diese benötigen ein dafür eingerichtetes Firebase-Projekt; eine kostenpflichtige Abrechnungsfreigabe wurde nicht vorgenommen. Ohne bereitgestellte Functions sind Registrierung und Anfragen nutzbar, aber die Café-Einlösung nicht.

  1. In Firebase Authentication den Anbieter E-Mail/Passwort aktivieren und die tatsächliche Website-Domain autorisieren.
  2. Die vorhandenen Firestore-Regeln sichern, mit firestore.rules vergleichen und die neue Fassung bereitstellen. Die bisherigen Daten werden nicht gelöscht.
  3. Die Dateien zusammen auf HTTPS bereitstellen. Erst dort die Registrierung, E-Mail-Bestätigung und Wiederanmeldung auf dem iPhone testen. Die iPhone-Dateivorschau unterstützt keine Registrierung.
  4. Der bestehende Admin-Zugang braucht weiterhin admins/UID mit active: true. Niemand kann sich im Formular selbst zum Admin oder freigegebenen Betrieb machen.

Es wurde nichts veröffentlicht und keine kostenpflichtige Firebase-Funktion aktiviert.

Zahlung per Überweisung

Der Kunde fragt sein Abo an. Du prüfst das passende Angebot und teilst ihm die korrekten Bankdaten, den Betrag und eine eindeutige Zahlungsreferenz mit. Nach echtem Zahlungseingang schaltest du das Abo im Admin frei. Die App kann den Kontoeingang ohne Bankanbindung nicht automatisch prüfen. Bankdaten wurden nicht erfunden oder voreingestellt.

Partnerbestätigung

Neue Café- und Autowäsche-Firmen müssen die Erbringung vereinbarter Leistungen und das Verbot doppelter Berechnung im Formular bestätigen. Fassung und Zeitpunkt werden mit der Firmenanmeldung gespeichert. Die beigefügten neuen Regeln verlangen diese Angaben und verhindern spätere Änderungen durch den Antragsteller. Bestehende Firmen werden nicht nachträglich automatisch verpflichtet.

Deine Dateien

Entpacke das vollständige ZIP-Paket. Alle HTML-Dateien müssen zusammen im Ordner Mo‘s Abo-Komplett bleiben. Öffne zuerst index.html. Café, Autowäsche, Firmen und Admin sind mit den aktuellen Dateien dieses Pakets verknüpft. Es wurde nichts hochgeladen oder veröffentlicht.

Die HTML-Dateivorschau auf dem iPhone führt JavaScript unter Umständen nicht aus. Für Anmeldung und Datenfunktionen bitte in einem richtigen Browser öffnen, zum privaten Test am Computer über localhost. Firebase benötigt Internetzugriff und eine passende autorisierte Anmeldedomain.

Firebase einmal einrichten

  1. Nutze das bestehende Firebase-Projekt Mo‘s Abo. Für beide Apps gilt derselbe Firebase-Benutzer und derselbe Admin-Nachweis.
  2. Sichere die aktuell veröffentlichten Firestore-Regeln. Vergleiche sie mit der unten stehenden vollständigen Vorlage. Sie basiert auf dem letzten hier vorhandenen Kaffee-Stand; mögliche spätere Änderungen deiner Live-Regeln dürfen nicht verloren gehen.
  3. Übernimm die geprüfte Vorlage nach dem Vergleich in Firestore. In diesem Auftrag wurden die Regeln nicht veröffentlicht.
  4. Dein bestätigtes Konto benötigt weiterhin admins/DEINE-UID mit active: true. Diese Freigabe kann nur über einen bereits berechtigten Firebase-Zugang eingerichtet werden. Die HTML-Dateien können sich keine Adminrechte geben.
  5. Öffne admin.html, melde dich an, wähle Autowäsche und aktiviere die Kategorie. Kunden und Firmen können dasselbe bestehende Mo-Konto verwenden.

Der erste echte Ablauf

  1. Firma registriert ihren Betrieb in autowaschen.html.
  2. Admin gibt die Firma frei und legt ein Paket mit Preis, Anzahl, Gültigkeitsdauer und Vergütung je Nutzung an.
  3. Kunde meldet sich mit bestätigter E-Mail an und fragt das Paket an.
  4. Admin prüft eine manuelle Zahlung oder kostenlose Freigabe, dokumentiert die Referenz und gibt das Abo frei.
  5. Kunde fragt eine Wäsche an. Das Guthaben wird erst beim Bestätigen durch die zugeordnete Firma abgezogen.
  6. Firma prüft den Kunden vor Ort und bestätigt. Anfrage, Guthaben und Abrechnungsbeleg werden zusammen gespeichert. Eine zweite Bestätigung derselben Anfrage wird abgewiesen.
  7. Admin sieht bestätigte Wäschen und offene Partnervergütungen. Eine bereits ausgeführte Überweisung kann mit Referenz dokumentiert werden; die App führt keine Zahlung aus.

Die Firmenbestätigung ersetzt keine physische Kundenprüfung. Die Anfragekennung ist eine Zuordnungshilfe und kein Zahlungsnachweis.

Neue Tarife & Bonusfreigaben

Basic: 24,90 € / 2 Wäschen im Monat / 1 Aufbereitung / 2 Gratiswäschen / 5 € Amazon-Gutschein. Plus (TOP-ANGEBOT): 34,90 € / 3 Wäschen / 2 Aufbereitungen / 3 Gratiswäschen / 10 € Gutschein. Premium: 54,90 € / 5 Wäschen / 3 Aufbereitungen / 4 Gratiswäschen / 15 € Gutschein. Aufbereitungen und Jahresboni gelten je zwölf bezahlte Monate.

  1. Im Admin Autowäsche öffnen, eine freigegebene Firma im Angebotsformular auswählen und „Basic / Plus / Premium als Entwürfe anlegen“ drücken. Die Entwürfe sind zunächst inaktiv.
  2. Partnervergütungen bestätigen lassen: 5 € brutto je Basiswäsche und 50 € brutto je Basis-Aufbereitung sind die vorgegebenen, noch zu bestätigenden Konditionen. Erst danach die Angebote aktivieren.
  3. Nach einer Kundenanfrage das Abo wie bisher prüfen und freigeben. Danach im Abschnitt „Monatszahlungen & Bonusfreigaben“ einmal „Bonusvertrag starten“.
  4. Jeden tatsächlich bezahlten Monat separat mit Zahlungsreferenz erfassen, auch den ersten Monat. Die Abo-Freigabe allein zählt nicht als Monatszahlung. Es zählen nur vollständige Monatszahlungen; kostenlose Freigaben zählen nicht. Ein Monat kann je Vertrag nur einmal verbucht werden. Buchungen erfolgen zeitlich aufsteigend; zukünftige Monate zählen noch nicht.
  5. Bei der ersten erfassten Zahlung bleibt das bereits freigegebene reguläre Guthaben erhalten. Bei späteren Monatszahlungen wird es auf das Monatskontingent zurückgesetzt; reguläre Restwäschen verfallen. Bonusansprüche werden separat geführt.
  6. Nach der sechsten bestätigten Monatszahlung werden die tariflichen Aufbereitungen verfügbar. Nach der zwölften folgen Gratiswäschen und Gutschein. Im zweiten Bonusjahr liegen die Schwellen bei 18 und 24, danach entsprechend weiter.
  7. Kunden fragen freigeschaltete Bonusleistungen an. Die zugeordnete Firma bestätigt Aufbereitungen und Gratiswäschen nach Durchführung. Der Admin dokumentiert eine tatsächlich erfolgte Gutscheinausgabe mit Referenz. Die App kauft oder versendet keine Amazon-Gutscheine.

Basis-Aufbereitung: vereinbarte Innen-/Außenreinigung. Politur, intensive Polsterreinigung und Zuschläge für große oder stark verschmutzte Fahrzeuge sind gesondert zu vereinbaren. Bonusleistungen sind bei aktivem Abo einlösbar. Ein Tarifwechsel übernimmt den Bonusstand nicht automatisch; bestehende Bonusverträge werden nicht überschrieben.

Neue Daten werden unter services/carwash/loyaltyContracts, monthlyPayments, bonusRequests und bonusRedemptions gespeichert. Monatszahlungen sind unveränderliche Belege. Die neuen vollständigen Firestore-Regeln müssen übernommen werden, bevor diese Funktionen echte Daten schreiben können. Gutscheinwerte stehen getrennt von den Partnervergütungen; Gutscheine werden nicht als Partnerauszahlung summiert.

Weitere Kategorien

Kaffee bleibt vollständig im bisherigen Admin-Bereich erhalten. Die Übersicht liest dieselben alten Kaffee-Belege. Autowäsche, Restaurant und spätere Bereiche verwenden die Struktur services/KATEGORIE/…. Restaurant ist als Verwaltungsbereich vorbereitet und hat noch keine eigene Kunden-App. Über „Weitere Kategorie vorbereiten“ kannst du weitere Bereiche anlegen; deren Kundenseiten müssen danach angebunden werden.

Jede Kategorie hat eigene Firmen, Angebote, Paketanfragen, Kunden-Abos, Nutzungsanfragen und Belege. Ein globaler Admin kann alle verwalten. Firmen dürfen nur eigene Vorgänge sehen, Kunden nur eigene Kontodaten. Sitzung und Berechtigungen bleiben Firebase-abhängig; keine eigene Login-Kopie wird im HTML gespeichert.

Stand & Grenzen

Arbeitsstand ohne Veröffentlichung, ohne erfundene Preise und ohne Beispieldaten. Es gibt keine automatische Abbuchung. Nach einer bestätigten Monatszahlung werden Monatskontingent und Bonusstand nach den neuen Tarifregeln aktualisiert. Jede Freigabe ist ein Paket mit einem vom Admin festgelegten Ablaufdatum. Kundenzahlungen werden manuell geprüft. Preise verstehen sich so, wie du sie im Angebot festlegst; steuerliche und vertragliche Angaben sind vor dem Verkauf zu ergänzen.

Die bestehende Datenschutzerklärung ist weiterhin ein Entwurf und muss für Autowäsche ergänzt werden. Im Admin sind neue Listen auf 200 Datensätze begrenzt; bei Erreichen der Grenze wird die Unvollständigkeit angezeigt. Firmen und Kunden laden bis zu 100 Belege.

              && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['status','cancelledAt'])
              && request.resource.data.status == 'cancelled' && request.resource.data.cancelledAt == request.time
              && subscription(resource.data.uid).activeRequestId == id && afterSubscription(resource.data.uid).activeRequestId == '')
            || (resource.data.companyId == request.auth.uid && company(request.auth.uid)
              && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['status','confirmedAt','confirmedBy'])
              && request.resource.data.status == 'confirmed' && request.resource.data.confirmedAt == request.time
              && request.resource.data.confirmedBy == request.auth.uid && usable(subscription(resource.data.uid))
              && subscription(resource.data.uid).activeRequestId == id && afterSubscription(resource.data.uid).activeRequestId == ''
              && afterSubscription(resource.data.uid).remaining == subscription(resource.data.uid).remaining - 1
              && ledgerAfter(id).requestId == id));
        allow delete: if false;
      }
      match /redemptions/{id} {
        allow read: if verified() && (admin() || resource.data.uid == request.auth.uid || (resource.data.companyId == request.auth.uid && company(request.auth.uid)));
        allow create: if verified() && company(request.auth.uid)
          && request.resource.data.keys().hasOnly(['requestId','uid','customerName','companyId','companyName','offerId','offerName','quantity','payoutCents','paymentStatus','createdAt'])
          && request.resource.data.requestId == id && request.resource.data.companyId == request.auth.uid
          && request.resource.data.quantity == 1 && request.resource.data.paymentStatus == 'open'
          && request.resource.data.createdAt == request.time
          && requestBefore(id).status == 'pending' && requestAfter(id).status == 'confirmed'
          && requestBefore(id).uid == request.resource.data.uid
          && requestBefore(id).companyId == request.auth.uid
          && subscription(request.resource.data.uid).activeRequestId == id && usable(subscription(request.resource.data.uid))
          && afterSubscription(request.resource.data.uid).remaining == subscription(request.resource.data.uid).remaining - 1
          && afterSubscription(request.resource.data.uid).activeRequestId == ''
          && request.resource.data.customerName == subscription(request.resource.data.uid).name
          && request.resource.data.companyName == subscription(request.resource.data.uid).companyName
          && request.resource.data.offerId == subscription(request.resource.data.uid).offerId
          && request.resource.data.offerName == subscription(request.resource.data.uid).offerName
          && request.resource.data.payoutCents == subscription(request.resource.data.uid).payoutCents;
        allow update: if admin() && resource.data.paymentStatus == 'open'
          && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['paymentStatus','paidAt','paidBy','paymentReference'])
          && request.resource.data.paymentStatus == 'paid' && request.resource.data.paidAt == request.time
          && request.resource.data.paidBy == request.auth.uid && request.resource.data.paymentReference is string
          && request.resource.data.paymentReference.size() >= 3 && request.resource.data.paymentReference.size() <= 160;
        allow delete: if false;
      }
    }

    match /services/{serviceId} {
      function lc(uid) { return get(/databases/$(database)/documents/services/$(serviceId)/loyaltyContracts/$(uid)).data; }
      function la(uid) { return getAfter(/databases/$(database)/documents/services/$(serviceId)/loyaltyContracts/$(uid)).data; }
      function br(id) { return get(/databases/$(database)/documents/services/$(serviceId)/bonusRequests/$(id)).data; }
      function ba(id) { return getAfter(/databases/$(database)/documents/services/$(serviceId)/bonusRequests/$(id)).data; }
      function bl(id) { return getAfter(/databases/$(database)/documents/services/$(serviceId)/bonusRedemptions/$(id)).data; }
      function partner(uid) { return verified() && get(/databases/$(database)/documents/services/$(serviceId)/companies/$(uid)).data.active == true; }
      function tariff(key) { return key == 'basic' ? {'price':2490,'units':2,'detail':1,'wash':2,'voucher':500} : key == 'plus' ? {'price':3490,'units':3,'detail':2,'wash':3,'voucher':1000} : {'price':5490,'units':5,'detail':3,'wash':4,'voucher':1500}; }
      function available(c,kind) {
        return kind == 'detail' ? int((c.paidMonths + 6) / 12) * tariff(c.planKey).detail - c.detailUsed
          : kind == 'bonusWash' ? int(c.paidMonths / 12) * tariff(c.planKey).wash - c.bonusWashUsed
          : int(c.paidMonths / 12) * tariff(c.planKey).voucher - c.voucherIssuedCents;
      }
      function activeSubscriber(uid) {
        let s=get(/databases/$(database)/documents/services/$(serviceId)/subscriptions/$(uid)).data;
        return s.active == true && s.validUntil > request.time && s.companyId == lc(uid).companyId && s.offerId == lc(uid).offerId;
      }
      function receiptAfter(id) { return getAfter(/databases/$(database)/documents/services/$(serviceId)/monthlyPayments/$(id)).data; }
      match /subscriptions/{uid} {
        allow get: if verified() && partner(request.auth.uid) && resource.data.companyId == request.auth.uid && lc(uid).companyId == request.auth.uid;
      }
      function benefitCounterUpdate(uid) {
        let d=request.resource.data;
        let kind=bl(d.lastBenefitId).kind;
        return d.lastBenefitId != resource.data.lastBenefitId && bl(d.lastBenefitId).uid == uid
          && ((kind == 'detail' && d.diff(resource.data).affectedKeys().hasOnly(['detailUsed','lastBenefitId','updatedAt','updatedBy']) && d.detailUsed == resource.data.detailUsed+1)
           || (kind == 'bonusWash' && d.diff(resource.data).affectedKeys().hasOnly(['bonusWashUsed','lastBenefitId','updatedAt','updatedBy']) && d.bonusWashUsed == resource.data.bonusWashUsed+1)
           || (kind == 'voucher' && d.diff(resource.data).affectedKeys().hasOnly(['voucherIssuedCents','lastBenefitId','updatedAt','updatedBy']) && d.voucherIssuedCents == resource.data.voucherIssuedCents+tariff(resource.data.planKey).voucher))
          && available(resource.data,kind)>0;
      }
      match /loyaltyContracts/{uid} {
        allow get: if own(uid) || admin() || (verified() && resource.data.companyId == request.auth.uid && partner(request.auth.uid));
        allow list: if admin() || (verified() && resource.data.companyId == request.auth.uid && partner(request.auth.uid));
        allow create: if serviceId == 'carwash' && admin()
          && request.resource.data.keys().hasOnly(['uid','name','companyId','companyName','offerId','contractId','planKey','planName','priceCents','monthlyUnits','paidMonths','lastPeriodStart','lastReceiptId','detailUsed','bonusWashUsed','voucherIssuedCents','lastBenefitId','washPayoutCents','detailPayoutCents','updatedAt','updatedBy'])
          && request.resource.data.uid == uid && request.resource.data.planKey in ['basic','plus','premium']
          && request.resource.data.priceCents == tariff(request.resource.data.planKey).price
          && request.resource.data.monthlyUnits == tariff(request.resource.data.planKey).units
          && request.resource.data.paidMonths == 0 && request.resource.data.lastPeriodStart == timestamp.value(0)
          && request.resource.data.lastReceiptId == '' && request.resource.data.detailUsed == 0
          && request.resource.data.bonusWashUsed == 0 && request.resource.data.voucherIssuedCents == 0
          && request.resource.data.lastBenefitId == '' && request.resource.data.washPayoutCents == 500 && request.resource.data.detailPayoutCents == 5000
          && request.resource.data.contractId is string && request.resource.data.contractId.size() >= 16
          && request.resource.data.companyId == get(/databases/$(database)/documents/services/$(serviceId)/subscriptions/$(uid)).data.companyId
          && request.resource.data.offerId == get(/databases/$(database)/documents/services/$(serviceId)/subscriptions/$(uid)).data.offerId
          && audit();
        allow update: if audit() && ((admin()
          && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['paidMonths','lastPeriodStart','lastReceiptId','updatedAt','updatedBy'])
          && request.resource.data.paidMonths == resource.data.paidMonths+1 && request.resource.data.paidMonths <= 1200
          && request.resource.data.lastPeriodStart > resource.data.lastPeriodStart && request.resource.data.lastPeriodStart <= request.time
          && receiptAfter(request.resource.data.lastReceiptId).uid == uid
          && receiptAfter(request.resource.data.lastReceiptId).contractId == resource.data.contractId
          && receiptAfter(request.resource.data.lastReceiptId).periodStart == request.resource.data.lastPeriodStart
          && receiptAfter(request.resource.data.lastReceiptId).amountCents == resource.data.priceCents)
          || (verified() && benefitCounterUpdate(uid)
            && ((bl(request.resource.data.lastBenefitId).kind == 'voucher' && admin())
              || (bl(request.resource.data.lastBenefitId).kind in ['detail','bonusWash'] && resource.data.companyId == request.auth.uid && partner(request.auth.uid)))));
        allow delete: if false;
      }
      match /monthlyPayments/{id} {
        allow read: if admin() || (verified() && resource.data.uid == request.auth.uid);
        allow create: if serviceId == 'carwash' && admin()
          && request.resource.data.keys().hasOnly(['uid','contractId','period','periodStart','amountCents','reference','recordedAt','recordedBy'])
          && id == request.resource.data.contractId+'--'+request.resource.data.period
          && request.resource.data.period.matches('^[0-9]{4}-(0[1-9]|1[0-2])$')
          && request.resource.data.periodStart == timestamp.date(int(request.resource.data.period.split('-')[0]),int(request.resource.data.period.split('-')[1]),1)
          && request.resource.data.contractId == lc(request.resource.data.uid).contractId
          && request.resource.data.amountCents == lc(request.resource.data.uid).priceCents
          && request.resource.data.periodStart is timestamp && request.resource.data.periodStart <= request.time
          && request.resource.data.periodStart > lc(request.resource.data.uid).lastPeriodStart
          && request.resource.data.reference is string && request.resource.data.reference.size() >= 3 && request.resource.data.reference.size() <= 160
          && request.resource.data.recordedAt == request.time && request.resource.data.recordedBy == request.auth.uid
          && la(request.resource.data.uid).paidMonths == lc(request.resource.data.uid).paidMonths+1
          && la(request.resource.data.uid).lastReceiptId == id;
        allow update, delete: if false;
      }
      match /bonusRequests/{id} {
        allow read: if admin() || (verified() && (resource.data.uid == request.auth.uid || (resource.data.companyId == request.auth.uid && partner(request.auth.uid))));
        allow create: if serviceId == 'carwash' && verified() && request.resource.data.uid == request.auth.uid
          && request.resource.data.keys().hasOnly(['uid','contractId','customerName','companyId','companyName','kind','status','requestedAt'])
          && request.resource.data.kind in ['detail','bonusWash','voucher']
          && request.resource.data.contractId == lc(request.auth.uid).contractId

          && request.resource.data.companyId == lc(request.auth.uid).companyId && request.resource.data.companyName == lc(request.auth.uid).companyName

          && available(lc(request.auth.uid),request.resource.data.kind)>0 && activeSubscriber(request.auth.uid);
        allow update: if verified() && resource.data.status == 'pending'
          && ((own(resource.data.uid) && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['status','cancelledAt'])
              && request.resource.data.status == 'cancelled' && request.resource.data.cancelledAt == request.time)
            || (request.resource.data.diff(resource.data).affectedKeys().hasOnly(['status','confirmedAt','confirmedBy'])
              && request.resource.data.status == 'confirmed' && request.resource.data.confirmedAt == request.time && request.resource.data.confirmedBy == request.auth.uid
              && bl(id).requestId == id && la(resource.data.uid).lastBenefitId == id
              && ((resource.data.kind == 'voucher' && admin()) || (resource.data.kind != 'voucher' && resource.data.companyId == request.auth.uid && partner(request.auth.uid)))));
        allow delete: if false;
      }
      match /bonusRedemptions/{id} {
        allow read: if admin() || (verified() && (resource.data.uid == request.auth.uid || (resource.data.companyId == request.auth.uid && partner(request.auth.uid))));
        allow create: if serviceId == 'carwash' && verified()
          && request.resource.data.keys().hasOnly(['requestId','uid','contractId','customerName','companyId','companyName','offerId','offerName','kind','quantity','payoutCents','voucherCents','deliveryReference','paymentStatus','createdAt'])
          && request.resource.data.requestId == id && br(id).status == 'pending' && ba(id).status == 'confirmed'
          && request.resource.data.uid == br(id).uid && request.resource.data.kind == br(id).kind
          && request.resource.data.contractId == lc(request.resource.data.uid).contractId
          && request.resource.data.customerName == lc(request.resource.data.uid).name
          && request.resource.data.companyId == lc(request.resource.data.uid).companyId
          && request.resource.data.companyName == lc(request.resource.data.uid).companyName
          && request.resource.data.offerId == lc(request.resource.data.uid).offerId
          && request.resource.data.quantity == 1 && request.resource.data.paymentStatus == 'open' && request.resource.data.createdAt == request.time
          && activeSubscriber(request.resource.data.uid) && available(lc(request.resource.data.uid),request.resource.data.kind)>0
          && la(request.resource.data.uid).lastBenefitId == id
          && ((request.resource.data.kind == 'detail' && partner(request.auth.uid) && request.resource.data.companyId == request.auth.uid
              && request.resource.data.payoutCents == lc(request.resource.data.uid).detailPayoutCents && request.resource.data.voucherCents == 0
              && la(request.resource.data.uid).detailUsed == lc(request.resource.data.uid).detailUsed+1)
            || (request.resource.data.kind == 'bonusWash' && partner(request.auth.uid) && request.resource.data.companyId == request.auth.uid
              && request.resource.data.payoutCents == lc(request.resource.data.uid).washPayoutCents && request.resource.data.voucherCents == 0
              && la(request.resource.data.uid).bonusWashUsed == lc(request.resource.data.uid).bonusWashUsed+1)
            || (request.resource.data.kind == 'voucher' && admin() && request.resource.data.payoutCents == 0
              && request.resource.data.voucherCents == tariff(lc(request.resource.data.uid).planKey).voucher

          && request.resource.data.paidBy == request.auth.uid && request.resource.data.paymentReference is string
